# Contributing to Samunnati repositories

Follow the SOP - GitHub Usage for Developers and the SOP - GitHub Production Merge & Access Restriction.

## Branch names
- feature/<ticket-id>-<short-name>
- bugfix/<ticket-id>-<short-name>
- hotfix/<ticket-id>-<short-name>

## Commit messages
- Format: `<TICKET-ID>: <what changed>`  e.g. `AL-6465: add Highmark report view`
- Small, focused commits; no build outputs, data extracts or customer data
- Never commit passwords, keys, tokens, connection strings or publish profiles

## Pull requests
- Fill every field of the PR template; production PRs need UAT sign-off and must be raised one working day before release
- At least one approval from someone other than the author
